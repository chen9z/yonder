# Yonder（仓库 herdc）：Herdr 的 Android 客户端

Yonder 是 [Herdr](https://github.com/herdrdev/herdr-app) 桌面版在手机上的同级客户端：连上 PC（局域网 SSH，
外网走 Tailscale）后，看到的是同一个世界——同样的 space、tab、分屏、终端和 agent 状态，改动双向实时同步。

## 关键事实（决定了架构）

- Herdr 桌面版本身不持有工作区：它是 herdr-core（`hc`）的客户端，经 `hc connect` 说 JSON-RPC 2.0，
  `hello {framed:true}` 后切到分帧模式（`[channel u32 LE][kind u8][len u32 LE][payload]`）。
- 共享结构（space → tab → 分屏树）存在 core 的 **`herdr-app` 文档**里（`doc.get` / `doc.set`，带版本 CAS）。
  每块屏幕的焦点、缩放、当前 tab、已读状态是**私有视图**，不写进文档。手机端读写同一份文档，
  就和桌面多屏完全同构。
- 终端都是 core 的终端；Herdr 用 `herdr.space` / `herdr.tab` 标签认领，`herdr.seen` 标签跨屏共享已读回合。
- core 没有 TCP 监听；远程访问的官方方式就是 `ssh host '…herdr-core connect'`（herdr 自己连远程机器也这么做）。
  本机 core 已经聚合了它添加的远程机器（`vps/t7` 这类地址），手机连上 PC 的 core 即可看到全部机器。

## 总体结构

```
┌──────────── Android (nsh, Rust) ──────────────┐        ┌──────── PC ────────┐
│ app/      UI：space/tab/分屏/终端/agents/面板  │        │ sshd               │
│   └ herdc-engine  无头控制器（移植自 window.rs）│  SSH   │  └ sh -c '…        │
│        ├ herdc-model  model/layout/mirror      │◄──────►│     herdr-core     │
│        ├ herdc-wire   JSON-RPC + 分帧多路复用   │  exec  │     connect'       │
│        ├ herdc-term   VT（alacritty_terminal）  │ channel│        │           │
│        └ herdc-ssh    russh：密码/密钥/主机指纹  │        │   herdr-core ◄─ herdr-app
└────────────────────────────────────────────────┘        └────────────────────┘
```

| crate | 职责 |
|---|---|
| `herdc-wire` | 与传输无关的 core 客户端：分帧编解码、调用/应答路由、attach 流与 credit 流控、`events.subscribe` 快照 + 事件应用 |
| `herdc-ssh` | russh 客户端：密码 / 私钥登录，主机指纹首次信任并固定（TOFU），exec 通道跑 Herdr 同款 pipe 命令行（支持 `HC_SESSION`） |
| `herdc-model` | **原样复用** herdr-app 的 `layout.rs`、`model.rs`、`mirror.rs`（Apache-2.0，见 NOTICE），文档读写与桌面逐字段一致 |
| `herdc-engine` | 无头控制器：把 window.rs 里的业务逻辑（命令、认领、对账、已读共享、提醒、文档 CAS 刷写）移植成可测试的逻辑 |
| `herdc-term` | 终端仿真：喂字节、出带样式的行快照、滚动回看、按键编码（应用光标键、bracketed paste）、查询应答走 AUTOMATIC_INPUT |
| `app` | nsh Rust 应用：手机/平板自适应 UI；终端用 canvas 画网格，隐藏输入框接软键盘，快捷键栏补 Esc/Ctrl/Tab/方向键 |

## 复刻范围

core 能力和内置 mods 的功能全部复刻，界面按手机重新设计；用户自定义的 JS mods 和 layout 不在手机上运行
（它们依赖 gpui-shell 运行时）。

| 桌面 | 手机 |
|---|---|
| spaces mod（侧栏、按机器分组、拖动排序） | 首页：按机器分组的 space 列表，状态点，长按重命名/关闭/移动 |
| tabs mod / terminals-bar | 顶栏下的 tab 条（空间有两个以上 tab，或有收起的 tab 时）：状态、名字，点一下切换，长按重命名 / 收起 / 关闭；最后是“收起 N 个”，点开选一个放回来（`tab.select` 会取消收起）；点顶栏标题切换空间 |
| 分屏树（row/column/stack） | 平板：真实分屏；手机：一次一个 pane + pane 切换条（和 tab 一样高，描边不填色以区分两条；shell 的 `me@host:~/a/b` 标题只写 `b`，重名的按位置加序号），缩放即全屏 |
| agents mod（working/blocked/done/idle，子 agent） | Agents 页：跨 space 列表，排序同桌面，不止一组时按 置顶 / 等你处理 / 完成 / 工作中 / 空闲 加小标题；点进 peek。blocked 的 agent 直接显示它问的最后几行和菜单选项（Codex / Claude Code 的编号菜单），点选项即发对应按键；“回复…”先按 Esc 离开菜单再发文字（菜单上直接回车会选中高亮的“是”）。工作区里，别处的 agent 等你时弹出同样的问题卡片，一直留到它不再等（正看着它时不显示），可点 ✕ 先放下 |
| peek（无 pane 的 worker） | Agents 页里子 agent 挂在父 agent 下；无 pane 的点开是 Peek 页，可 keep 成 tab 或跳到所在 pane |
| toast / 声音提醒 | 应用内 toast（blocked / done）。系统通知要等 NSH 发布通知 API（0.4.0 没有），后台常驻需要前台服务（打包的 APK 不能加 Java） |
| palette（命令面板） | 命令面板：同一套命令名和参数 |
| new-menu | 顶栏的 `+`：终端、本机探测到的 agent 程序（结果按机器缓存，先显示上次的再在后台重查）、新 space、新建/打开 worktree |
| machine-add | 首页菜单「Add a machine…」：电脑 `~/.ssh/config` 里的 host（含 Include）或手填，经 `machine.add` 添加；需要回答时提示在终端里跑的命令 |
| files / changes / worktree | 对应页面，经 `machine.exec`（mods 原样的命令行）实现，远程目录每 10 s 刷新；打开的文件用 nsh-base 的只读 `Editor` 显示，按文件名高亮 |
| help（快捷键表） | 手机没有快捷键，不复刻；命令页列出全部命令 |
| settings | 手机端设置：字号（终端上也可双指缩放）、打字时适配、语言（跟随系统 / English / 中文）、本机密钥 |

窗口类命令（最小化、最大化、桌面 app 更新、遥测）不适用于手机，不复刻。herdc 只做 Android：没有桌面入口。

## 关键设计决定

- **用 herdr-app 自己的模型代码**而不是按文档重写：文档格式、分屏增删的权重分配、命名规则、
  attention 规则都与桌面逐行一致，并且直接带上它们的单元测试。
- **SSH 是唯一的鉴权边界**，PC 端零安装。主机指纹首次连接后固定，变化时拒绝并提示；
  密码加密保存在手机上，不往电脑上写任何东西（不自动配置公钥）。密码方式被拒就是密码错了，不再拿它试 keyboard-interactive：macOS 的 sshd 在密码失败后走 keyboard-interactive 会一直不回应（OpenSSH 客户端也一样）。只有电脑不接受 `password` 方式时才用 keyboard-interactive；登录最多等 30 s；连上电脑、交换密钥最多等 10 s（只接连接不说话的也算连不上）。保存的密码被拒（电脑改了密码）就不再重试（每次失败都会记到账户上），提示条上给“重新输入密码”。电脑上已经有手机公钥的（用户自己从设置页复制过去加的），就用钥匙登录。
  不支持 RSA 主机/用户密钥：russh 的 `rsa` 特性锁定的 `rsa` 预发布版与 NSH 依赖冲突，只支持 ed25519 和 ECDSA。
- **只 attach 可见的 pane**，离屏即 CLOSE，节省流量和电量；尺寸遵循 core 的“最后活跃的观看者定尺寸”，
  手机打开或切到一个终端就按手机的行列数接管（像 tmux 归最近用的客户端）：桌面的 145 列缩到手机上字小得没法看。代价是 Mac 上这个终端暂时变窄，桌面一打字就拿回去，手机改回旁观。设置里关掉“终端按手机尺寸排版”时才是旧的规矩：默认 observe，用户开始输入才接管尺寸。关掉时的两个例外：手机自己开的终端一开始就按手机的行列数；
  没人持有的终端（处在 core 的 headless 尺寸）也由手机接管，别的屏幕一打字就放手、改回旁观。
  手机开过哪些终端随“上次的界面”一起存下来，app 重启后这些终端仍按手机的行列数（以前重启后变成旁观，显示成桌面的大小）。
- **断线重连**：指数退避，重连后重新取快照、重新读文档、重新 attach（core 保证程序不受影响）。
  app 回到前台时先用 3 s 探一下线路，不通就立刻重拨（系统冻结进程后，断掉的线要等 keepalive 超时才会发现）。
  断线原因是网络时，app 每秒探一次电脑的 SSH 端口，一通就重拨，不等引擎的退避（最长 10 s）。
- **启动即回到上次的电脑**：退出前在哪台电脑就直接连哪台；在首页菜单或设置里“断开”离开后，下次从电脑列表开始。
- **界面语言**：文字以英文写在代码里（`t!("…")`），中文在 `app/src/i18n.rs` 查表；测试保证每个 `t!` 都有译文。
  引擎来的文字（提醒、确认框、命令说明、状态词）在显示时翻译；拼出来的（`"{name} needs you"`）按 `TEMPLATES` 里的模板认。
- **终端手势**：上下滑翻历史，左右滑（超过 80 pt，且横向为主）切到下一个 / 上一个 tab，双指缩放字号，长按选文字。Agents 页里看 agent 的终端不切 tab。tab 一换（滑动、tab 条、命令），终端上方短暂显示“第几个 / 共几个 · 名字”。程序开了鼠标模式（lazygit、htop 等）时，轻点还会在那一格发一次左键点击（按下 + 松开），同时照常弹键盘。终端的每一行是一块单独的 canvas，它们不接触摸（`PointerEvents::None`），手指的位置才是相对整个终端算的（否则行号总是第一行）。
- **终端里的链接**：长按菜单最上面列出屏幕上离手指最近的最多 3 个链接（`herdc_term::Screen::links`：按显示内容找 `http(s)://`，折行的行接起来找（手机收到的屏幕是一行一行重画的，不带折行标记，所以写满整行的也当作接着下一行），去掉句末的标点和没配对的右括号；程序用 OSC 8 标的链接也算），点一下 `open_url`。
- **终端里的文件路径**：长按菜单里接着列出离手指最近的最多 2 个文件路径（`herdc_term::Screen::file_paths`：带目录或带行号、文件名有扩展名的，如 `src/a.rs:42:7`、`./b.py`、`/tmp/x.md`；网址和 `~/` 开头的不算，因为家目录在电脑那边才知道；中日韩文字不算路径的一部分，“改了src/a.rs。”这样贴着汉字的也能认出来）。太长时菜单里按目录截断，留下文件名和行号（“…/app/src/terminal.rs:400:5”）。点一下打开文件页：相对路径从这个窗格的当前目录算（没有就用空间的目录），绝对路径直接打开；说了行号就跳到那一行并高亮，Markdown 这时先显示源码。
- **断线提示条**：工作区里浮在终端上面，不占位置：它出现、消失时终端的行列数不变（以前每次重连都让远端终端改一次大小，桌面也跟着重排）。首页照旧排在列表上方。
- **图标**：顶栏和按钮都用 `assets/chrome` 里的 Lucide 线条图标（`ui::icon_button` 收图标名），不用 ‹ ⋯ ✕ 这类文字字符，各处粗细一致。
- **选择面板**（`pick::menu`）：所有选项菜单（新建、切换空间、Agents 排序，tab / 空间 / agent / 终端 / 电脑的长按菜单，首页 ⋯，收起的 tab，语言）都用 app 自己的底部面板，样子同“更多”面板：每行前面是图标（线条图标、agent 的程序图标或空间色块），可分区，当前的那个加粗、行尾打勾，空间还带状态。关闭、删除、停止、离开这类会丢东西的项是红色。根页面挂一次（`pick::host`，电脑列表页也在它下面），同一时间只有一个，后一个来时前一个算取消。每行有 `test_id` `pick-<id>`，测试按 id 点。确认框（`ui::confirm` / `ui::agree`）还是系统的。
- **Agents 列表行**：两行，名字在上，下面小字是“在做什么 · 哪台机器”（都没有就只有一行），右边只留时间、置顶和状态。
- **工作区顶栏**：标题前是空间的色块（和首页同一个颜色），后面是空间状态（空闲不画）。有 tab 条时副标题只写在哪台机器，tab 条接着顶栏、中间不画线；没有 tab 条时副标题写“tab · 机器”。正在看的空间被关掉（最后一个窗格、菜单）就回首页，不跟着 core 跳到下一个空间（可能在另一台机器上）。
- **电脑列表与连接表单**：电脑列表也是卡片（`ui::card`，和设置页同一个），一台电脑一张：电脑一行在上，上次的空间在下。连接表单里 Session 收在“更多选项”下（有值时展开）；主按钮连接时自己转圈、写着在做什么（“正在连接电脑…”“正在登录…”），只有出错才另起一行红字；在 app 里编辑连接有返回箭头，不再放“取消”。电脑列表页由 app 根部的 `dynamic` 画，页面里读信号要 untracked，不然信号一变整页重建（以前保存编辑后就是这样，`adding` 已被丢弃还被写）。
- **设置页**：分组卡片（`POPOVER` 色的圆角卡片放在 `CANVAS` 上，组内行之间是从文字处开始的细线，小标题和卡片里的文字对齐），每行前面一个线条图标。电脑那一行右边是线路状态的圆点（连上绿、连接中黄、断开红）。复制密钥会提示“已复制”和要放到哪（`~/.ssh/authorized_keys`）。列表行而不是大按钮：去别的页的行带 ›，就地做事的行是强调色，会丢东西的（离开这台电脑）是红色。按键栏页同样：每个键的 ↑ ↓ ✕ 是淡色小图标，到头的那个变淡不可点，“恢复默认”是强调色的行；添加机器页里已添加的机器和 ssh 配置里的主机一样，右边是强调色的字（重命名 / 添加），点整行。开关是 `ui::toggle`：NSH 0.4 的 `switch` 只有行为没有样子，直接用什么也画不出来。
- **提醒**：最多显示最新的两条，其余收成“还有 N 条”，点开全部；键盘弹起时只显示最新一条，挪到顶栏（和 tab 条）下面，不挡正在输入的那一行。工作区返回键和首页 Agents 的角标：有等你处理的就数它们（红），否则数已完成的（蓝）。
- **tab 名字**：没起名的 tab 显示它里面 agent 的标题，不再只是一个数字；起了名的照旧。
- **密钥存放**：保存的密码和手机的 ed25519 私钥用 Android Keystore 里的 AES-GCM 密钥加密后再放进 NSH 的 Storage（`app/src/vault.rs`，JNI 调 `javax.crypto`）。Keystore 的密钥不出手机，所以备份或拷走的数据打不开；打不开时再要一次密码。NSH 生成的 manifest 带 `allowBackup`，改不了，所以靠加密而不是关备份。
  Android 12 以前拿不到 JVM，改用 app 自己的 AES-256-GCM 密钥（`ring`），放在 `no_backup` 目录、权限 0600，备份和换机迁移都不带它（前缀 `aside1:`）。
- **打包**：`app/apk.sh`（`--install` 顺带装到手机）：只打 arm64-v8a，fat LTO，用 `~/.config/herdc/release.jks` 正式签名（密码在 macOS 钥匙串 `herdc-release-keystore`）；签名不可用时停止，只有显式 `--debug` 才使用调试签名。名字 Yonder（包名 `dev.yonder.app`；以前叫 Herdr / `dev.herdc.app`，换包名不能覆盖升级）。桌面图标（`app/icon.png`）为深色底上的米白色终端笑脸和橙色状态点。仓库和 crate 仍叫 herdc，用户看不到。
  build 号由 `app/build-number` 或 `HERDC_BUILD` 指定，和提交号一起编进 app，设置 → 关于里显示；更新记录在 `CHANGELOG.md`。
  nsh-base 保留默认的 `highlight` 功能，文件查看器按文件名提供语法高亮。
- **诊断信息**：设置 → 关于 → 复制诊断信息：版本、系统、偏好、密钥怎么存的、电脑地址和用户、线路和各机器的状态、数量。不含密码和密钥。
- **CI**：`.github/workflows/check.yml` 在 Ubuntu 上装指定版本的 herdr-core（`HC_VERSION`），跑 `scripts/check.sh`。
- **大量输出限速**：viewer 以 512 KiB/s 归还 credit（`Attach::pace`）。输出超过这个速度持续 1 s，就算“落后”，断开重新 attach，从当前屏幕开始，不再一个字节一个字节追 core 那边最多 4 MiB 的积压。省流量、省电，刷屏结束后 0.5 s 内看到最后的输出。
- **后台不收输出**：app 进后台时 viewer 放开终端（`Engine::set_shown(false)`），状态事件照收；回前台从当前屏幕重新 attach。以前后台刷屏 24 s 照样收 16 MB。
- **SSH 压缩**：优先 `zlib@openssh.com`，其次 `zlib`，电脑不支持就不压缩。
- **重画限频**：终端最多每 33 ms 画一次（约 30 fps）；刷屏时主要耗 CPU 的是绘制，不是解析。
- **外接键盘**：终端有键盘焦点时，Ctrl/Alt + 字母、方向键、Home/End/PgUp/PgDn、Esc、Tab、F1–F12 直接发给终端（NSH `on_key_with`，`When::Always`）；Ctrl+Q、F11 系统保留。
- **拖动分屏**：宽屏（≥ 720 pt）时，两个按权重分的窗格之间有一条可拖的分界线（`herdc_engine::seams`）。松手后两边按新位置重新分权重（`layout.resize`），每边至少一成；固定 px 的窗格不动。
- **先画上次的样子**：每台电脑连上并读完布局后，把它的 View 存起来（`seen.<id>`，有变化时最多 10 s 后存一次，进后台、断开时也存；超过 256 KiB 就不存 terminals）。
  再打开时先画这份，线路状态用实时的，读完新的就换成新的。电脑列表在每台电脑下列出它上次的 spaces，圆点是当时最需要关注的状态；点一个 space，连上后直接到那里；直接打开时回到上次看的 space。
- **手机自己的选择**：每个 space 看的是哪个 tab、焦点、缩放、收起的 tab、哪些提醒看过，由 engine 存进每台电脑一个文件（`Options.store`，像桌面的 `view.json`），在 app 的 `files/views/<id 的十六进制>.json`（`link::view_file`）。重启后先画 `seen.<id>`，engine 读完布局再按这份恢复。删电脑时删掉；编辑连接改了 id 时，同一把主机密钥、用户和 session 才跟过去，否则删掉（`carry_view_in` / `forget_view_in` 按目录单测；release 包不能 `run-as`，手机上看不到这个目录）。app 私有目录统一由 `app_folder(子目录)` 求出（`files/views`、vault 的 `no_backup`）。
- **多个 session**：添加电脑时可以填 `HC_SESSION`（只允许字母、数字和 `._-/`，因为要拼进远端 shell），同一台电脑的不同 session 是不同的条目（`id` 末尾加 `/session`）。
- **首页空间列表**：本机用电脑自己的名字，保留机器名大小写，本机在前、远程机器按名字排序。机器标题是“箭头 + 名字 …… +”（没连上时 `+` 换成状态的字），组之间留空；箭头可折叠整组空间，按电脑和机器存在 prefs，重启后保留；当前空间所在机器也允许折叠，选中空间不会自动展开。空间不显示标签页数量，只有非 main/master、不同于空间名及仓库目录名的分支才显示第二行，没内容就只画一行。行尾是空间里最要紧的 agent 状态（运行中转圈、等你红点、完成蓝点，空闲不画）。
- **Agents 列表**：「Needs you」只做状态提醒，点击可打开对应终端；列表与提醒浮层不读取终端问题，也不代发按键或回复。子 agent 已在别人的后代树中时不再占顶层行，置顶例外；已保留的后代优先取 AgentView 的状态，done 仍归 idle。主文字按桌面 Priority 视图显示空间加有意义的标签页或 agent 标题，数字自动名仅在重名时补上；空标题回退程序/app 名，远程行追加机器名。状态旁显示变化距今的 <1m / Nm / Nh / Nd，每 30 s 刷新。时间用 core 记录的 `status_ms`（电脑上状态变化的那一刻，不是手机连上的时刻），没有时才用引擎自己看到变化的时间；旧缓存缺失时默认为 0（暂不显示时间）。
- **空间排序**：每个 space 右边的点阵拖动柄（淡色）可以上下拖，按行高算移动几格，拖动时被越过的行让出位置，松手执行 `space.move`（只在同一台机器的 spaces 里移动）。
- **空间菜单**：长按 space 时，它是不是 git、是不是 worktree 先看缓存，没有就最多等 0.35 s；还没结果就先给出“工作树… / 文件 / 变更”（页面自己会说不是 git），后台查到的结果留给下次。
- **按键栏可编辑**：设置 → 按键栏：栏上的键可以前移、后移、移除，下面是可以加上的键（`\` `` ` `` `:` 等符号、Del、Ins、F1–F12）。最下面可以加自己的键：一段文字（`/compact`、`y`、`git status`），默认输完再按回车，显示成文字后面跟一个回车图标，读屏念“…，然后回车”。按键栏页的滚动视图用 `KeyboardTaps::Handled`，键盘开着时点 + 第一下就能加上。存成 `say:<文字>`，要回车的结尾带 `\n`；回车晚 250 ms 发，否则 Codex 会把紧跟在一串输入后的回车当成粘贴里的换行。存在 prefs 里。↵ 固定在最左，⌄（收起键盘）固定在最右，不随中间的键滚走。
- **按键栏的按法**：方向键、Del、PgUp/PgDn 按住 0.45 s 后每 50 ms 连发，松手即停（最多连发 400 次）。Ctrl / Alt 点一下只管下一个键（蓝框），连点两下锁定（实心），再点一下松开。
- **文件和变更**：列表可以下拉立即刷新（不用等 10 s 的定时刷新）；文件和 diff 的字号跟终端字号走。diff 页右上角是“第几个 / 共几个”和上一个 / 下一个文件，换文件替换当前页，返回直接回列表。
- **电脑列表**：每台电脑下面只列最急的 4 个空间（按原顺序），其余写“还有 N 个空间”；两台同名时副标题加上 `用户@地址:端口`。
- **焦点不共享**：手机上的焦点、放大、当前 tab 只记在本机引擎里，不发给 core，不会让桌面跟着跳。

## 会话与持久化边界

- `Engine` 的最后一个持有者释放，或显式调用 `close()`，会取消会话内的连接、后台请求和终端流。内部任务不持有会话所有权；关闭时清空发布给界面的客户端引用。
- 命令入口把 JSON 解析成有类型的参数，错误类型不得被当作缺省值。每条同步命令显式完成；异步回调被取消或因重连过期时返回错误，不会自动宣告成功。
- `docs::Slot` 独占布局同步状态及其转换规则，外层通过 `prepare`、`apply`、`connection` 等操作驱动同步。`state/documents.rs` 负责协调，`state/projection.rs` 负责构造视图。
- 缓存状态词通过有限枚举校验，不使用全局字符串驻留或永久分配。未知词使缓存解析失败，由实时状态重建界面。
- Android 上两种加密方式都失败时停止保存并报告错误。电脑列表先完整序列化，再替换存储；手机密钥对保存在同一个记录中，旧记录在新记录保存成功后移除。桌面无头测试保留显式的明文后端。

## 恢复后的版本与打包

原 Git 历史无法恢复，当前仓库从恢复源码建立新的基线。`recovery/` 中的恢复证据和归档保留在本地，不进入 Git。

`app/build-number` 从 50 开始，后续每次分发递增，也可通过 `HERDC_BUILD` 显式指定。版本号不依赖提交数量。

- `sh app/apk.sh --check`：仅检查版本参数。
- `sh app/apk.sh`：正式签名构建；缺少密钥或钥匙串解锁失败会停止。
- `sh app/apk.sh --debug`：明确选择调试签名。
- 追加 `--install` 才会安装到设备。正式密钥默认位于 `~/.config/herdc/release.jks`，可通过 `HERDC_KEYSTORE` 指定路径。
